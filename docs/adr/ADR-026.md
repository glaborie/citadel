# ADR-026: one CLI for humans and agents

Status: accepted
Date: 2026-11-27

## Context

The operational surface of this repository is sixteen files in `scripts/`, one `Makefile`
target each, and a live-test module that mints its own credentials. That is fine for the
person who wrote them and hostile to everyone else:

- **Two entry points for one action.** `make eval-samples ARGS="--replay --html …"` passes
  flags through a variable; `scripts/read-eval-samples.py` takes them directly. Nothing says
  which is canonical.
- **Three credential paths.** `read-eval-samples.py` reads `CITADEL_DB_DSN_FILE`,
  `start-run.py` mints a Keycloak token, `mlflow-gateway-bootstrap.py` reads a mounted
  secret. Each is right; none is discoverable.
- **Prose output, exit code 0 either way.** `scripts/mlflow-ui.sh --status` prints whether
  the sidecar is up and exits 0 regardless. A human reads it; an agent cannot.
- **No single "is the stack healthy" question.** Answering it today means five commands
  across three tools.

The agent case matters as much as the human one: an agent driving this repo needs to know
*what it can do* and *whether it worked* without parsing English.

## Decision

One entry point, `citadel`, installed as a console script from `src/citadel/cli/`, with
subcommands that own a verb each. The existing scripts stay until their subcommand exists;
a subcommand is a thin layer over the same code, never a reimplementation.

Rules every subcommand follows:

1. **`--json` prints one document and nothing else.** No banners, no progress lines, no
   colour on stdout when the flag is set.
2. **Exit codes are meaningful and stable.** `0` success, `1` the command ran and the thing
   failed, `2` usage, `3` refused by policy or a guard, `4` a dependency was unavailable. An
   agent distinguishes "denied" from "broken" without reading a message.
3. **A credential is never printed** except by an explicit command that exists to print one
   (`citadel token`), and then only to stdout.
4. **Nothing prompts.** Destructive actions take `--yes` (or `--dry-run` to show the plan).
5. **Idempotent by default.** Running a command twice is safe; anything that cannot be is
   named.
6. **Every failure carries a hint.** A check that finds MLflow unreachable says which
   command makes it reachable, so the next step does not need the documentation.

The first subcommand is `citadel doctor`, because it is the question both audiences ask
first and the one that currently has no answer.

## Consequences

- The Makefile keeps its targets as one-line aliases (`make doctor` → `citadel doctor`), so
  muscle memory keeps working while the CLI becomes the documented surface.
- `src/citadel/cli/` is inside the package, so `mypy --strict` and the smell gate apply to
  it like the rest of `src/`.
- One HTTP helper carries the single `dynamic-urllib` suppression for the whole CLI, with
  the same justification the eval reader has: the URLs are operator configuration, not
  actor input.
- Tests inject probes instead of touching the network, so the doctor's rules (what counts as
  healthy, which exit code follows) are testable without a stack.
- Migration is incremental and revisable: each subcommand lands when it has a test and a
  line in `docs/operations/cli.md`, and no script is deleted before its replacement is
  proven against the running stack.
