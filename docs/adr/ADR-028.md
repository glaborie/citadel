# ADR-028: Content taint travels with the tool call and refuses an agent approver

**Status:** Accepted
**Date:** 2026-11-28

## Context

The researcher labels untrusted pages with `untrusted_external` and instructing
pages with `prompt_injection` (`docs/security/tool-tiers.md`, T0 section). The
orchestrator accumulates these labels for the run, but until now they reached
only `run.end.safety_flags`, which is written after the run finishes. The human
gate on T1 writes is the backstop for prompt injection (RT-INJ-02/05), yet the
approver was never told that the run proposing the write had read flagged or
untrusted content: `ToolCall` had no field to carry the labels,
`approval_requests` had no column to persist them, and the console had nothing
to render. An approver saw `restart_service {"service": "postgres"}` from user
alice, which looks routine.

The gap also weakened ADR-022: an approving agent is exactly the component a
prompt injection is trying to steer, so an agent that approves a call made
after injected content was read is the injection succeeding end to end.

## Decision

1. `ToolCall` carries `content_flags: list[str]` — the labels the run has
   accumulated so far. The orchestrator copies `sorted(flags)` into every tool
   call it delegates after a flagged observation, so a call made at step N
   carries the taint of steps 1..N-1: the call itself is what the approver
   judges.
2. The specialist persists the flags on the `approval_requests` row
   (migration `0010`, `content_flags jsonb NOT NULL DEFAULT '[]'`). The flags
   come from the workflow's accumulated state, never from a request body.
3. The console renders the flags on the pending-approval list and prominently
   on the detail view; a `prompt_injection` flag shows a refusal-styled warning
   above the arguments. `untrusted_external` alone is shown but does not change
   the flow: it is the steady state of every research run.
4. **A call flagged `prompt_injection` is never an agent's decision to make.**
   `authorize_approval` (ADR-022 chokepoint) refuses an agent approver with
   `approval.prompt_injection` before any policy lookup; only a human may
   decide, and the console's mandatory reason already applies. The flags are
   read back from the pending row by the API, so a caller cannot claim the call
   is clean.
5. The `policy.decision` audit event carries the flags beside the tool and
   args hash, so the ledger shows the taint at decision time, not only at
   `run.end`.

Refused rather than routed to a human approver automatically: an agent refusal
leaves the call pending, and a human can still decide it inside the TTL. No
new approval class, no extra row.

## Implementation (2026-11-28)

- `citadel/workflows/types.py`: `ToolCall.content_flags`; the orchestrator
  populates it and the specialist preserves it across the approved rebuild.
- `citadel/approval_requests.py` + `migrations/0010_approval_content_flags.sql`:
  the pending row persists the flags.
- `citadel/policy/authorize.py`: `ApprovalAuthorization.content_flags` and the
  `approval.prompt_injection` denial in the fail-closed chain (after four-eyes,
  before the policy lookup).
- `citadel/api/app.py`: the agent path reads `content_flags` from the pending
  row and passes it to `authorize_approval`.
- `citadel/ui/app.py`: a Flags column on the pending list and a warning on the
  detail view.
- Red-team case `RT-HITL-08` proves an agent cannot approve an
  injection-tainted call.

## Consequences

- **Pros**: The approver sees the one fact that should make them suspicious
  before deciding; an injected instruction can no longer reach a write through
  an agent approver, closing the ADR-022 path that prompt injection was best
  positioned to abuse. The audit trail carries the taint at decision time.
- **Cons**: A missed detection still flows — the flags are a detector's label,
  not proof of cleanliness, so this is defence in depth on top of the human
  gate, not a replacement. The pending row gains a column and the console one
  more field to render. Agent approvers lose authority on tainted calls until a
  human decides, which is the intended cost.
