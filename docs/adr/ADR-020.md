    # ADR-020: Isolated untrusted web research pipeline

    **Status:** Accepted  
    **Date:** 2026-11-23  
    **Last modified:** 2026-11-23

    ## Context

    Researcher is the main indirect prompt-injection path. Public web content must never inherit tool authority or internal network reachability.

    ## Decision

    1. Researcher gets only search_web and fetch_page; no Docker/GitHub tools and no arbitrary code execution.
2. Use self-hosted SearXNG plus a trafilatura fetcher with size/MIME/time limits, no cookies, no internal targets and no cloud metadata addresses.
3. Label fetched content untrusted_external, strip active content and pass it through injection/guardrail checks before it reaches a model.
4. Apply DLP to outbound search queries; Researcher may recommend actions but only the orchestrator can delegate them through normal policy and HITL.

    ## Consequences

    - **Pros**: Free, self-hostable research with a clear untrusted-content boundary and no paid search API.
    - **Cons**: Search quality is lower than paid APIs; fetched pages may still be incomplete or stale.
