# ADR-020: Isolated untrusted web research pipeline

**Status:** Accepted  
**Date:** 2026-11-23  
**Last modified:** 2026-11-26

## Context

Researcher is the main indirect prompt-injection path. Public web content must never inherit tool authority or internal network reachability.

## Decision

1. Researcher gets only search_web and fetch_page; no Docker/GitHub tools and no arbitrary code execution.
2. Use self-hosted SearXNG plus a trafilatura fetcher with size/MIME/time limits, no cookies, no internal targets and no cloud metadata addresses.
3. Label fetched content untrusted_external, strip active content and pass it through injection/guardrail checks before it reaches a model.
4. Apply DLP to outbound search queries; Researcher may recommend actions but only the orchestrator can delegate them through normal policy and HITL.

**Amended 2026-11-26 (issue #131):** implemented as two services and one worker.
`worker-researcher` owns `search_web` and `fetch_page` and executes them itself;
the sandbox stays free of egress and of the fetcher. SearXNG is pinned by tag and
digest and answers JSON. The fetcher resolves a URL, refuses any answer that is
not global unicast, pins the connection to the checked address, allows only
ports 80/443, re-checks each redirect, sends no cookies, caps the body at 2 MB
(truncated and marked) and accepts only an HTML/plain-text MIME set.

The label is applied in the worker: the text is prefixed `untrusted_external`,
and a deterministic lexical detector adds `prompt_injection` when the page
instructs the reader. Both flags are written to `tool.call.content_flags` and
copied to `run.end.safety_flags`; the run continues read-only. The two services
join a dedicated `web` bridge for egress and an internal `research` network with
the worker, never `edge`, and publish no port. Measurement is in
`docs/implementation-notes/issue-131-researcher.md`.

## Consequences

- **Pros**: Free, self-hostable research with a clear untrusted-content boundary and no paid search API.
- **Cons**: Search quality is lower than paid APIs; fetched pages may still be incomplete or stale.
