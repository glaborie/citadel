# ADR-008: Four-milestone evolution roadmap

**Status:** Accepted  
**Date:** 2026-11-23  
**Last modified:** 2026-11-23

## Context

A 16-feature stack cannot be delivered as one undifferentiated release. Each milestone needs a demonstrable exit test and explicit non-goals.

## Decision

1. v0.1: secure vertical slice — auth, tenant, policy, gateway, guarded read, HITL-gated write, audit, one trace and one golden trajectory.
2. v0.2: permission-aware RAG, Researcher specialist, SOPS+age secrets, offline eval suite.
3. v0.3: online grading, model comparisons, tenant-scoped cache, Prometheus metrics.
4. v0.4: MCP consume adapter, A2A seam, sandbox-only code mode, semantic routing.
5. Record non-goals per milestone; reconcile this roadmap with delivered scope before closing each one.

## Consequences

- **Pros**: Every milestone is demo-able and testable; scope creep has a named home.
- **Cons**: Later features are deliberately deferred, which may require explanation to reviewers.
