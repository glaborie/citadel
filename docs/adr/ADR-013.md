    # ADR-013: Fail-closed local DLP without a v0.1 reversible vault

    **Status:** Accepted  
    **Date:** 2026-11-23  
    **Last modified:** 2026-11-23

    ## Context

    A reversible token vault adds a high-value secret store. Presidio is the practical local detector, but detector failure must never degrade to plaintext egress.

    ## Decision

    1. Presidio with custom CH/EU recognizers runs locally on prompts, retrieval chunks, tool arguments/results and model output.
2. Detector unavailable or timeout blocks the request; PII is irreversibly redacted by default; secrets/credentials in tool input or output block and alert.
3. No reversible token vault in v0.1; reconsider only if a concrete tool requires operating on the original value.
4. Recognizer tests use realistic positive and negative samples; detector version is recorded in traces and audit events.

    ## Consequences

    - **Pros**: A defensible DLP story with no circular 'send data out to find if it is sensitive' problem.
    - **Cons**: Local model files add footprint and latency; irreversible redaction can break tools that need raw values.
