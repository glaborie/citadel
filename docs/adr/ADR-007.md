    # ADR-007: Hosted inference with local DLP only

    **Status:** Accepted  
    **Date:** 2026-11-23  
    **Last modified:** 2026-11-23

    ## Context

    No GPU/local LLM tier is wanted. Embeddings and rerank are inference too, and a fully hosted DLP would ship plaintext before discovering it is sensitive.

    ## Decision

    1. LLMs, embeddings and reranking run through OmniRoute to hosted providers; aliases strong/fast/judge map to concrete models in configuration.
2. Presidio plus custom CH/EU recognizers (AHV, Swiss IBAN, passport and similar) run locally on CPU because they must see plaintext to redact it.
3. Embedder and retriever sit behind interfaces so a local model can be swapped in without changing call sites.
4. All outbound prompts and tool arguments pass DLP before egress; detector failure blocks the request.

    ## Consequences

    - **Pros**: No GPU operations; low demo friction; DLP remains meaningful; provider switching stays cheap.
    - **Cons**: Content leaves the box for model calls; hosted rerank and embedding costs must be monitored.
